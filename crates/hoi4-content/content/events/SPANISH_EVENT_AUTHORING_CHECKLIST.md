# 西班牙内战中文事件校验清单

用于 P0.6 之后所有西班牙内战事件、新闻和决议文案审查。

- `title` 必须为中文。
- `description` 必须为中文，并包含具体场景、人物或机构、政治压力、选择代价。
- `EventOption.name` 必须为中文。
- 事件 id、flag、文件名、effect 名称继续使用英文 snake_case 或 ASCII tag。
- 重要国家事件至少两个选项。
- 重要国家事件至少设置一个后续 flag 或产生机制效果。
- 重要选择必须有代价，不允许所有选项都是纯奖励。
- 新闻事件可以只有一个确认选项，但必须写出国际反应、国内政治后果或后续压力。
- `news.scw_*` 保持 `scope: News`，不得承担玩家阵营选择。
- 阵营选择和路线选择使用 `scope: Country`，确保 pending 时暂停。
- 玩家切换阵营必须使用 `SwitchPlayerCountry("TAG")`，不得在 app 层写一次性特殊逻辑。
- 后续事件读取的 flags 必须来自路线图 P1.5 的第一批命名，除非明确扩展清单。
